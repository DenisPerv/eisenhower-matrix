Why agents need a matrix too

An agentic system with many roles behaves like a team of people. Better instructions or a new API do not fix everything: most misses are process misses, such as the wrong task first, a deadline nobody held, or a fact an agent never had.

Tuning, like a team

Set what comes first, which deadlines hold, which facts are missing and which references to work from.
